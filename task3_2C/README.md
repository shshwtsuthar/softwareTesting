# SIT333 Task 3.2C - Equivalence Class Testing using JUnit

This is a clean Maven/Eclipse project for SIT333 Task 3.2C.

## What is included

- `src/main/java/sit707_tasks/DateUtil.java` - original DateUtil logic.
- `src/main/java/sit707_tasks/Main.java` - simple manual run class.
- `src/test/java/sit707_tasks/DateUtilTest.java` - JUnit 4 equivalence class test cases.
- `pom.xml` - Maven project file with JUnit 4.13.2.

## How to import in Eclipse

1. Extract this zip file.
2. Open Eclipse.
3. Go to `File > Import > Maven > Existing Maven Projects`.
4. Select the extracted `task3_2C` folder.
5. Finish import.
6. Right-click `src/test/java/sit707_tasks/DateUtilTest.java`.
7. Select `Run As > JUnit Test`.
